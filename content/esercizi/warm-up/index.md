# Warm-up — dal client a WILSON

Questa unità introduce il workspace del corso e il flusso di lavoro tra le postazioni locali, GitHub e WILSON. Mac e client di laboratorio sono ambienti locali; GitHub sincronizza il repository; WILSON è l'ambiente HPC remoto. Le istruzioni operative del cluster sono raccolte nella [guida pratica a WILSON](../../workflow/lab-client-wilson.md); gli esercizi mantengono procedure e obiettivi autonomi.

## Percorso

1. [Creare il workspace locale del corso](exercise01-workspace.md)
2. [Completare un giro di sincronizzazione GitHub](exercise02-git-sync.md)
3. [Trasferire, connettersi e documentare una sessione WILSON](exercise03-wilson-session.md)
4. [Hello, World!](exercise04-hello-world.md)

Il primo, il terzo e il quarto esercizio seguono il flusso del warm-up del corso,
con l'username di esempio sostituito da `fbellina2`. Il giro GitHub è specifico di
questo repository personale. Ogni esercizio specifica dove eseguire i comandi e
quali valori adattare; i dettagli di macchina e software non verificati vanno
controllati sul sistema effettivo.
