# Esercitazioni

Le esercitazioni della relazione, numerate in ordine pedagogico. Ognuna segue lo
schema fisso: **consegna** (evidenziata), **parametri**, **implementazione**,
**procedura di validazione**, **risultati e plot**, **commenti**, **checkpoint**.

1. [Esercitazione 1 — Problema di Basilea](es01-basilea.md) — aritmetica in
   virgola mobile, ordine di somma, troncamento contro arrotondamento.
2. [Esercitazione 2 — Parallel Hello, World!](es02-parallel-hello-world.md) —
   thread OpenMP, rank MPI, layout ibrido e scheduling Slurm.
