# High-Performance Computing for AI Applications in Physics

This book is a personal, evolving collection of theory, worked examples,
exercises, notebooks, and source code for the HPC4AI course.

The material is organized by lecture. Each lecture should connect theoretical
ideas to practical computational work rather than treating exercises as an
unrelated appendix.
