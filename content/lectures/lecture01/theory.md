# Teoria — Ambiente di lavoro

Il lavoro del corso distingue sviluppo locale, sincronizzazione del repository e calcolo remoto. Mac e client di laboratorio sono ambienti locali; GitHub sincronizza il repository; WILSON è l'ambiente HPC remoto.

Per procedure di accesso, trasferimento, moduli e job, consulta la [guida pratica WILSON](../../workflow/lab-client-wilson.md). I dettagli di macchina e software non verificati vanno controllati sul sistema effettivo.
