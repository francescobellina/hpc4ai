# Ambiente di lavoro e primi esercizi

Questa unità introduce il workspace del corso e il flusso di lavoro tra le postazioni locali, GitHub e WILSON. Le istruzioni operative del cluster sono raccolte nella [guida pratica a WILSON](../../workflow/lab-client-wilson.md); gli esercizi mantengono procedure e obiettivi autonomi.

## Percorso

1. Creare il workspace locale del corso.
2. Sincronizzare il repository con GitHub.
3. Trasferire file e aprire una sessione WILSON seguendo le istruzioni dell'esercizio.
4. Compilare ed eseguire un programma Hello, World!.

Le quattro attività sono disponibili nell'indice laterale. Ogni esercizio specifica dove eseguire i comandi e quali valori adattare.
