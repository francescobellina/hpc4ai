# Lecture 2 — Computing architectures: performance models

Condensed personal notes from the course chapter *1.5 Performance models*
(Roofline), part of the *Computing architectures* section.

## Learning objectives

By the end of the lecture, you should be able to:

- compute the arithmetic (operational) intensity of a simple kernel;
- read a Roofline plot and classify a kernel as memory-bound or compute-bound;
- locate the ridge point and predict whether an optimization can help;
- name what the basic model does not capture (in-core ceilings, bandwidth
  ceilings, locality walls, latency-bound cases).
